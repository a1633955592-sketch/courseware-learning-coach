# 课件学习老师 · Courseware Learning Coach

把用户提供的课件组织成连续的学习过程：先建立知识地图，再按概念关系讲解，结合原图、公式、例题和练习推进。用户说“继续”时接回原来的知识线索。

这是一个以中文编写的 Agent Skill，默认随用户的语言教学。它提供教学工作流，不包含模型、课程资料或在线服务。

## 能做什么

- **从整体开始**：首次查看当前课件的结构，解释用途、模块关系与学习目标，再深入当前模块。
- **按概念教学**：连接跨页内容，解释公式的条件、变量与意义，追踪代表性推导或例题。
- **连续学习与就地答疑**：保留暂停点和教学粒度，插问后接回主线；普通“继续”避免重复全量备课。
- **按需图示与交互**：优先原图或简图；只有交互能改善理解时才制作轻量演示。
- **保留可靠进度**：在有意义的检查点保存状态，区分已讲、用户自述理解和实际作答证据。

适合依据 Lecture Notes、PDF、PPT、Tutorial 和习题学习课程；单纯翻译、摘要或无关的独立解题不需要启用本 Skill。

## 安装到 Codex

在支持 `$skill-installer` 的 Codex 环境中发送：

```text
使用 $skill-installer 安装 GitHub 仓库
a1633955592-sketch/courseware-learning-coach
根目录中的 Skill，安装名称为 courseware-learning-coach。
```

仓库根目录就是 Skill 目录，包含 `SKILL.md`、`references/`、`assets/` 和 `agents/`。如果安装后未出现，请重启或重新加载 Codex。

也可以从 GitHub 下载 ZIP，解压后把整个 `courseware-learning-coach` 文件夹放到宿主支持的用户 Skill 目录。Codex 的用户级发现路径之一是 `~/.agents/skills/`；请以所用版本为准，避免重复安装同名 Skill。

官方参考：[构建与安装 Skill](https://learn.chatgpt.com/docs/build-skills)。其他支持 Agent Skills 的宿主可使用自己的安装方式，能力与调用语法可能不同。

## 开始使用

上传或指定宿主能够访问的课程资料，然后发送：

```text
使用 $courseware-learning-coach 带我学习这份课件。
先说明整份课件解决什么问题、知识结构与章节关系，再从第一模块开始。
我的基础是：学过微积分，对电路基础不太熟。
```

同一个聊天中继续：

```text
继续，保持刚才的讲解粒度。
```

遇到理解障碍：

```text
这个推导我没跟上。请从图里的电流方向开始，把中间步骤展开，讲完接回主线。
```

跨聊天恢复：

```text
使用 $courseware-learning-coach，从我提供的 learning-state.md 继续。
我也提供了对应课件，请先恢复断点，再讲下一学习点。
```

新聊天需要能访问学习检查点和课程材料，安装 Skill 本身不会同步聊天记录或文件。

## 环境要求与可选能力

核心教学不依赖其他 Skill、专用 MCP 或付费 API。文件读取、联网、文件写入和浏览器预览由运行 Skill 的宿主提供：

| 能力 | 用途 | 不具备时 |
| --- | --- | --- |
| 读取 PDF／PPT 等文件 | 建立地图、定位课程内容 | 提供可读取的摘录；不能声称看过整份材料 |
| 查看原图／页面 | 核对电路、曲线、图表与符号 | 标明未核实部分，向用户索取必要内容 |
| 文件写入 | 保存学习检查点和演示 | 在聊天中给出可复制的检查点 |
| 联网搜索 | 按需补足具体理解缺口 | 先用已有材料，并说明验证限制 |
| 浏览器／代码执行 | 制作和验证交互演示 | 使用可用图示；不声称交互已验证 |

`study-plan-coach` 是可选搭配，本仓库不包含它；未安装也能教学并给出必要的学习安排。另开答疑聊天需要宿主有相应工具，且由用户明确提出；否则提供可复制的交接说明。

## 学习状态与资料

有文件写入能力时，默认检查点位置是当前工作区的：

```text
work/courseware/<course-slug>/topics/<scope-slug>/learning-state.md
```

已有状态沿用原位置；不修改原课件，不把动态进度写进 Skill。用户拒绝保存时使用聊天检查点。

本仓库只发布工作流和空白模板。自己的课件、试卷、答案、个人学习记录和账户凭据不属于发布内容。使用中的材料处理方式取决于所选宿主及工具。

## 如何检查是否符合预期

可用一份自己有权使用的短课件试用：

1. 首次学习应先给学习地图，再开始当前模块；细节不清时标明缺口。
2. 连续说“继续”应接回下一学习点，不重复整章扫描。
3. 追问一个概念后再继续，应恢复原主线并保持讲解粒度。
4. 没有 `study-plan-coach`、联网或文件写入能力时，应说明对应限制并继续可行部分。
5. 有检查点和原材料时，新聊天应能恢复；缺失的进展不能编造。

结构校验不能证明教学效果。模型仍可能误读材料或算错，需要对照原始资料核对关键公式、符号与答案；本 Skill 不保证成绩或覆盖率。
